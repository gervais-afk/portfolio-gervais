# Polices locales du portfolio

- **Manrope** — Mikhail Sharanda ; conversion variable avec Mirko Velimirovic. Source : https://github.com/google/fonts/tree/main/ofl/manrope ; fichier source `Manrope[wght].ttf`. Axe de graisse 200–800 conservé.
- **Newsreader** — Production Type. Source : https://github.com/google/fonts/tree/main/ofl/newsreader ; fichier source `Newsreader-Italic[opsz,wght].ttf`. Instance italique 400, taille optique 48.

Téléchargement le 16 novembre 2026 depuis le dépôt public Google Fonts, puis conversion WOFF2 et sous-ensemble latin / latin étendu pour le français et l’anglais avec fontTools. Les fichiers de licence SIL Open Font License sont conservés à côté des polices. Aucun appel à un service de polices pendant la navigation.

Les deux familles utilisent `font-display: swap`, avec polices système de repli. Le CV indépendant conserve sa typographie existante.
